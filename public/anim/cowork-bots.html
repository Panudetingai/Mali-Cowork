Cowork AI bots

สี่น้องบอทสีเหลือง เขียว ม่วง ดำ ที่เปลี่ยนท่าทางตามงานของ agent ตอนคิดและตอนทำงานจะสลับระหว่างร่างสามจุดกับหน้าปกติไปเรื่อย ๆ ตอนทำงานน้องจะดีใจ เด้งดุ๊กดิ๊ก มีสายรุ้งหมุนรอบตัว แล้วหดหายก่อนแยกร่าง

นำไปใส่ในแอป

ใช้ไฟล์นี้เป็น iframe แบบพื้นหลังโปร่งใส เลือกตัวด้วย ?embed=mochi, jelly, petal หรือ nori แล้วส่งสถานะจาก agent เข้าไปด้วย postMessage

<iframe id="bot" src="cowork-bots.html?embed=jelly&state=idle"
        style="border:0;width:160px;height:160px;background:transparent"></iframe>

// เมื่อ agent เปลี่ยนสถานะ: "idle" | "thinking" | "working" | "done"
document.getElementById("bot").contentWindow
  .postMessage({ state: "working" }, "*");

ถ้าวางไว้ในหน้าเดียวกันโดยตรง เรียก CoworkBots.set("petal", "thinking") ได้เลย ส่วน "done" จะกลับเป็น "idle" เองหลังฉลองเสร็จ
