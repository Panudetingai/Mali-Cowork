Cowork AI bots

แปดน้องบอทสีเหลือง เขียว ม่วง ดำ ฟ้า ชมพู ส้ม แดง ที่เปลี่ยนท่าทางตามงานของ agent ตอนคิดและตอนทำงานจะสลับระหว่างร่างสามจุดกับหน้าปกติไปเรื่อย ๆ ตอนทำงานน้องจะดีใจ เด้งดุ๊กดิ๊ก มีสายรุ้งหมุนรอบตัว แล้วหดหายก่อนแยกร่าง เพิ่มท่าใหม่อีกสี่แบบ แจ้งเตือนจะกลายเป็นสีแดงกระพริบ ทักทายจะแปลงร่างเป็นมือโบกไปมา ใช้เครื่องมือจะพ่นเครื่องมือและละอองสีสุ่มออกมา รอเชื่อมต่อจะซีดลงและมองหาสัญญาณ ส่วนรออนุญาตจะเอียงคอถามพร้อมกล่องข้อความรูปแม่กุญแจ

นำไปใส่ในแอป

ใช้ไฟล์นี้เป็น iframe แบบพื้นหลังโปร่งใส เลือกตัวด้วย ?embed=mochi, jelly, petal, nori, sora, momo, mikan หรือ ichigo แล้วส่งสถานะจาก agent เข้าไปด้วย postMessage

<iframe id="bot" src="agent-streaming-bots.html?embed=jelly&state=idle"
        style="border:0;width:160px;height:160px;background:transparent"></iframe>

// เมื่อ agent เปลี่ยนสถานะ: "idle" | "thinking" | "working" | "done"
//                          | "alert" | "welcome" | "tool" | "connection" | "permission"
document.getElementById("bot").contentWindow
  .postMessage({ state: "working" }, "*");

ถ้าวางไว้ในหน้าเดียวกันโดยตรง เรียก CoworkBots.set("petal", "thinking") ได้เลย ส่วน "done" จะกลับเป็น "idle" เองหลังฉลองเสร็จ
