กระบวนการ

อะไรที่ทำให้ token ลดลง

ทุกขั้นที่ agent คิด มันต้องส่งของ 4 อย่างให้โมเดลใหม่ทั้งหมด: คำสั่งระบบ, คำอธิบายเครื่องมือในตัว, คำอธิบายเครื่องมือของ connector และประวัติงานที่ผ่านมา ลองเปิดปิดแต่ละวิธีดูว่ากองไหนเล็กลง

คำสั่งระบบ เครื่องมือในตัว เครื่องมือ connector ประวัติงาน / ผลจากเครื่องมือ
ปิดทุกวิธี (แบบเดิม)
ตามที่เลือกไว้

ตัวเลขในส่วนนี้คำนวณจากขนาดจริงที่วัดได้ของแต่ละชิ้น (ตัวอักษร ÷ 4 ≈ token) และใช้กติกาเดียวกับโค้ด เป็นแบบจำลองให้เห็นภาพ ผลจริงดูที่กราฟด้านบน

ข้อมูลใช้งานจริง 14 วัน

token ในงานจริงหมดไปกับอะไร

จากประวัติ session ของ Mali ในเครื่องนี้: ผลจากเครื่องมือที่ถูกส่งซ้ำในทุกขั้นถัดไป แยกตามเครื่องมือ นี่คือเหตุผลที่ต้องย่อผลเก่าที่ใช้แล้ว

ส่วนแบ่งของ "ผลจากเครื่องมือที่ถูกส่งซ้ำ"

token ต่อคำตอบ (เฉลี่ย)

agent ของ Mali ใช้เยอะกว่าเพราะงาน Canva ยาวหลายขั้นและส่งคำอธิบายเครื่องมือของ connector ทุกขั้น ตัวเลขนี้เป็นงานต่างกัน ใช้ดูแนวโน้มเท่านั้น ส่วนการเทียบที่ยุติธรรมคือผลทดสอบด้านบน

เป้าหมาย

เป้า 90% อยู่ตรงไหนแล้ว

ตอนนี้: −31% เทียบ Mali เดิม, −60% เทียบ OpenCode

ยังไม่ถึง 90% ส่วนที่เหลือมาจากสิ่งที่ตัดไม่ได้โดยไม่เสียคุณภาพ เช่น คำสั่งระบบและเนื้อหาที่ agent ต้องอ่านจริง

ระบบลดได้มากขึ้นเมื่อมี connector หลายตัวพร้อมกัน (Canva + Notion + Gmail มีเครื่องมือเป็นร้อย) ในการทดสอบนี้มีแค่ตัวเดียว 32 tools

token ที่ไม่ได้ cache ขยับขึ้นเล็กน้อย (4.1k → 5.2k ต่องาน) เพราะการโหลดเครื่องมือกลางงานทำให้ต้นคำขอเปลี่ยน

ขั้นต่อไปที่จะลองวัด

  • ทดสอบกับโมเดล Claude: prompt caching เปิดแล้ว ส่วนที่ cache จะคิดราคาราว 10% แต่ยังไม่ได้วัดในรอบนี้
  • เพิ่มงานจริงแบบ Canva หลายขั้น และค้นเว็บหลายหน้า ซึ่งเป็นงานที่กิน token ที่สุดในการใช้งานจริง
  • ย่อประวัติให้เร็วขึ้น โดยวัดคุณภาพด้วยชุดทดสอบเดิมทุกครั้งก่อนเปิดใช้

ทดสอบอย่างไร

  • ทุกครั้งเริ่มจากสำเนาโฟลเดอร์ตัวอย่างใหม่ แล้วลบทิ้งหลังตรวจเสร็จ กันไม่ให้ agent ไปเจองานของรอบอื่น
  • connector "Acme CRM" รันในเครื่อง มี 32 tools ขนาดคำอธิบายพอ ๆ กับ connector จริง ไม่แตะบัญชีจริงของคุณ
  • OpenCode ได้ connector ตัวเดียวกัน และปิด connector อื่นของเครื่องไว้ ให้เท่ากันทุกฝั่ง
  • Mali รันแบบไม่มีหน้าจอ ใส่คำสั่งเรื่อง connector แบบเดียวกับที่แอปใส่จริง
